# LoliLand для macOS

Неофициальный установщик лаунчера LoliLand для Mac.

Официальный лаунчер выпускается только для Windows (`LoliLand.exe`), на Mac он не запускается.
Этот скрипт собирает обычное приложение `LoliLand.app`, которое работает на macOS напрямую, без Wine, CrossOver, Parallels и других эмуляторов.

> Проект не связан с администрацией LoliLand.

## Быстрый старт

```sh
mkdir -p ~/loliland && cd ~/loliland
curl -fLO https://raw.githubusercontent.com/liraquo/loliland-mac/main/install-loliland.sh
bash install-loliland.sh
```

Затем перетащите `~/loliland/LoliLand.app` в `/Applications`.
Логи лежат в `~/Library/Application Support/LoliLand/macos-app.log`.

## Подробная инструкция

### Что понадобится

- Mac с процессором Apple (M1, M2, M3, M4…) или Intel. На Intel установка не проверялась, но должна работать.

Ничего дополнительно ставить не нужно. Пароль от Mac скрипт **не спрашивает**: всё, что он создаёт, остаётся в вашей папке пользователя.

### Шаг 1. Скачайте скрипт

1. Откройте файл [`install-loliland.sh`](install-loliland.sh) здесь, на GitHub.
2. Нажмите кнопку **Download raw file** (значок со стрелкой вниз справа над текстом файла).
3. Файл окажется в папке **«Загрузки»**.

Создайте в «Загрузках» новую папку (например, `loliland`) и переместите скрипт туда. Рядом со скриптом появится готовое приложение, поэтому отдельная папка удобнее.

> Если Safari сохранил файл как `install-loliland.sh.txt`, переименуйте его, убрав `.txt` в конце.

### Шаг 2. Откройте Терминал

Терминал — стандартная программа macOS, в которой вводятся текстовые команды. Открыть её можно так:

- нажмите `⌘ Cmd` + `Пробел`, напечатайте «Терминал» (или «Terminal») и нажмите Enter;
- или в Finder: «Программы» → «Утилиты» → «Терминал».

Откроется окно с текстом и мигающим курсором.

### Шаг 3. Запустите скрипт

1. Напечатайте в Терминале `bash` и поставьте **пробел** после него. Enter пока не нажимайте.
2. Перетащите файл `install-loliland.sh` из Finder прямо в окно Терминала. Путь к файлу подставится сам, получится примерно так:

   ```
   bash /Users/имя/Downloads/loliland/install-loliland.sh
   ```

3. Нажмите **Enter**.

macOS может спросить, разрешить ли Терминалу доступ к папке «Загрузки». Нажмите «Разрешить».

### Шаг 4. Дождитесь окончания

Скрипт выполнит три шага и покажет, что делает:

```
1/3 Скачиваю launcher.jar с сервера LoliLand…
2/3 Скачиваю JetBrains Runtime с JCEF для macOS (aarch64)…
3/3 Создаю переносимое LoliLand.app с иконкой…

Готово: /Users/имя/Downloads/loliland/LoliLand.app
```

Пока идёт скачивание, видны полосы прогресса. Обычно всё занимает от одной до нескольких минут, в зависимости от скорости интернета.
**Не закрывайте Терминал, пока не увидите «Готово».** Если появилась строка «Ошибка: …», загляните в раздел [«Если что-то не работает»](#если-что-то-не-работает).

### Шаг 5. Перенесите приложение в «Программы»

В папке со скриптом появится `LoliLand.app` с иконкой LoliLand. Перетащите его в **«Программы»** (в боковой панели Finder). Так приложение будет находиться через Launchpad и Spotlight, его можно закрепить в Dock.

Терминал после этого можно закрыть.

### Шаг 6. Играйте

Откройте LoliLand, войдите в аккаунт и выберите сборку. Дальше всё как на Windows: лаунчер сам скачает игру.

## Где лежат файлы

| Что | Где |
|---|---|
| Приложение, Java, лаунчер | `LoliLand.app` (там, куда вы его перенесли) |
| Рабочая папка лаунчера | `~/Library/Application Support/LoliLand` |
| Лог текущего запуска | `~/Library/Application Support/LoliLand/macos-app.log` |
| Лог предыдущего запуска | `~/Library/Application Support/LoliLand/macos-app.log.1` |

`~` означает вашу домашнюю папку. Папка `Library` («Библиотеки») в Finder скрыта. Чтобы её открыть: в Finder нажмите `⇧ Shift` + `⌘ Cmd` + `G`, вставьте путь из таблицы и нажмите Enter.

Логи сами не разрастаются: хранятся только последние два запуска.

## Удаление

1. Перетащите `LoliLand.app` из «Программ» в Корзину.
2. Удалите папку `~/Library/Application Support/LoliLand` (как её открыть, написано [выше](#где-лежат-файлы)).

Больше скрипт ничего на Mac не создаёт.

## Если что-то не работает

| Сообщение | Что делать |
|---|---|
| «Не удалось получить манифест» или «Не удалось скачать» | Проблема с интернетом, или сервер LoliLand недоступен. Попробуйте позже или с VPN. |
| «SHA-512 не совпадает» или «Размер не совпадает» | Файл скачался не полностью. Запустите установку ещё раз. |
| «LoliLand сейчас запущен» | Закройте лаунчер и игру, затем повторите установку. |
| «…создан не этим установщиком» | Рядом со скриптом лежит другое приложение с именем `LoliLand.app`. Переместите его или запустите скрипт из другой папки. |
| `No such file or directory` | Путь к скрипту указан неверно. Повторите [шаг 3](#шаг-3-запустите-скрипт) и перетащите файл заново. |
| Приложение открывается и сразу закрывается | Откройте `macos-app.log` (см. [«Где лежат файлы»](#где-лежат-файлы)) и посмотрите последние строки, там будет ошибка. Её стоит приложить к issue. |

Если не помогло, [создайте issue](../../issues) и приложите текст ошибки из Терминала или лог.

## Как это работает

### Почему `LoliLand.exe` не запускается на Mac, а лаунчер можно запустить

`LoliLand.exe` — это не сам лаунчер, а небольшой загрузчик для Windows. При запуске он:

1. запрашивает у сервера LoliLand манифест (описание актуальных файлов);
2. скачивает Java для Windows и сам лаунчер, файл `launcher.jar`;
3. запускает `launcher.jar` через эту Java.

Сам лаунчер написан на Java, а Java-программы работают на любой системе, если там есть подходящая Java. Поэтому Windows-загрузчик не нужен: скрипт делает то же самое, что и он, только скачивает Java для macOS.

### Почему именно JetBrains Runtime

Интерфейс лаунчера — это веб-страница, встроенная в окно программы. Её показывает **JCEF**: встроенный в Java браузер на основе Chromium. Обычная Java его не содержит.

[JetBrains Runtime](https://github.com/JetBrains/JetBrainsRuntime) (JBR) — сборка Java от JetBrains, на которой работают IntelliJ IDEA и другие их программы. В её варианте `jbr_jcef` JCEF уже встроен, и есть нативные версии для Apple Silicon и Intel. Скрипт использует JBR 17.0.11 (b1312.2), лаунчер работает с этой версией.

### Что делает скрипт по шагам

1. **Проверки перед началом.** Скрипт убеждается, что запущен на macOS, что все нужные системные утилиты на месте, и что старое `LoliLand.app` рядом можно заменить: оно создано этим же скриптом и сейчас не запущено. Архитектура Mac определяется по железу, а не по `uname -m`, поэтому даже Терминал, запущенный через Rosetta, получит правильную версию Java.
2. **Лаунчер.** Скачивает манифест с `klauncher.loliland.pro` и сам [`launcher.jar`](https://klauncher.loliland.pro/api/updater/load/launcher), тот же файл, что получает Windows-загрузчик. Затем проверяет, что размер совпадает с манифестом, архив не повреждён, и внутри есть главный класс лаунчера LoliLand.
3. **Java.** Скачивает JBR с официального сервера JetBrains вместе с контрольной суммой и сверяет SHA-512. Если сумма не совпала, установка останавливается. Затем проверяет, что Java запускается и содержит JCEF.
4. **Сборка приложения.** Создаёт структуру `.app`, извлекает иконку из самого лаунчера и конвертирует её в формат macOS.

### Безопасность

- Скрипт не требует прав администратора и ничего не меняет в системе. Он создаёт файлы только рядом с собой и в `~/Library/Application Support/LoliLand`.
- Файлы скачиваются только по HTTPS и только из двух источников: сервер LoliLand и сервер JetBrains.
- Java проверяется по SHA-512 от JetBrains. Для лаунчера сервер LoliLand публикует только размер, поэтому проверяются размер, целостность архива и наличие главного класса.
- Приложение собирается на вашем Mac, а не скачивается готовым. Поэтому macOS не показывает предупреждение «разработчик не установлен».

Проверено на Apple Silicon. Я не разработчик проекта и не администратор, работа отдельных игровых сборок на macOS не гарантируется.
