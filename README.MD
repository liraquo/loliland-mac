## Установка

1. Кладём `install-loliland.sh` в отдельную папку. `LoliLand.exe` не нужен.
2. Запускаем терминал.
3. В окне Терминала вводим `bash` и добавляем **пробел**. Пока не нажимаем Enter.
4. Находим `install-loliland.sh` в Finder и перетаскиваем файл в окно Терминала — путь к нему подставится автоматически.
5. Нажимаем **Enter** и ждём сообщения «Готово». Не закрываем Терминал до завершения установки.
6. В папке рядом со скриптом появится `LoliLand.app`. Перетаскиваем его в **«Программы» (`/Applications`)**, так у вас будет нормальный ярлык для запуска.
7. Открываем приложение, входим в аккаунт и выбираем игровую сборку.

Если Terminal уже открыт в папке со скриптом, достаточно команды:

```sh
bash install-loliland.sh
```

**Приложение создаётся рядом со скриптом. В «Программы» автоматически не переносится.**

## Что делает скрипт

Скачивает [launcher.jar напрямую с сервера LoliLand](https://klauncher.loliland.pro/api/updater/load/launcher).
Затем скачивает JetBrains Runtime **17.0.11-b1312.2 с JCEF** для архитектуры
вашего Mac, проверяет файлы и собирает приложение с иконкой.
EXE не скачивается и не используется.

Всё необходимое находится внутри созданного `LoliLand.app` — после установки
исходная папка не нужна.
Существующее приложение не перезаписывается: для повторной установки
используйте новую папку.

Установка проверена на Apple Silicon. Поддержка Intel предусмотрена,
но не проверена. Совместимость игровых сборок проверяется отдельно.
